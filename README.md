# PointControl

PointControl is an innovative time-tracking and gamified adherence management system designed to optimize workforce punctuality and engagement.

## Tech Stack
- **Next.js 16** (App Router)
- **Tailwind CSS v4**
- **TypeScript**
- **Recharts** for visualizations
- **Framer Motion** for animations
- **Lucide React** for iconography

## Features
- **Gamified Adherence**: Tracks employee check-ins and check-outs, calculating adherence scores based on customizable tolerances.
- **Dynamic Leaderboards**: Highlights top performers and flags critical deviations, fostering a culture of punctuality.
- **Customizable Parameters**: Configure global or group-specific tolerance minutes, and set expected schedules per weekday.
- **Actionable Insights**: Detailed daily mirrors for each employee, allowing managers to justify or override discrepancies seamlessly.
- **Modern UI**: Fully responsive, dark mode supported, sleek interface built with Tailwind CSS.
